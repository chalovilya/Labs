# Лабораторная работа №6: Коллекции (Вариант 10)

## Задание 1: TopWords.java
Подсчёт частоты слов в файле text.txt и вывод топ-10.
- HashMap<String, Integer> для хранения пар "слово – количество"
- getOrDefault() для удобного увеличения счётчика
- Сортировка списка записей по убыванию через компаратор

## Задание 2: MyStack.java
Обобщённый стек на основе ArrayList.
- push() – добавление в конец
- pop() – удаление и возврат последнего элемента
- peek() – просмотр верхнего элемента без удаления
- isEmpty() и size() – вспомогательные методы

## Задание 3: SalesTracker.java (Вариант 10)
Учёт продаж с CopyOnWriteArrayList.
- CopyOnWriteArrayList<String> для потокобезопасного хранения списка проданных товаров с возможностью одновременного чтения и записи
- Команды: add <товар>, list, total, popular, exit
- Подсчёт общей суммы продаж (каждый товар считается за 1 продажу)
- Определение наиболее популярного товара
- Интерактивный режим через Scanner

## Запуск
```bash
java TopWords
java MyStack
java SalesTracker

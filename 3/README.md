# Лабораторная работа №3: Хэш-таблицы (Вариант 10 – Заказы в ресторане)

## Задание
Реализовать хэш-таблицу для учёта заказов в ресторане. Ключ – номер столика (или номер заказа), значение – объект Order.

## Классы
- HashTable<K, V> – собственная хэш-таблица с методом цепочек. Методы: put(), get(), remove(), size(), isEmpty(). Хэш-функция: Math.abs(key.hashCode() % table.length).
- Order – класс заказа с полями dishes (список блюд), totalCost (стоимость), orderTime (время заказа). Содержит конструкторы, геттеры/сеттеры, toString().
- OrderManager – управление заказами. Использует HashTable<Integer, Order> для хранения заказов по номеру столика. Методы: addOrder(), getOrder(), updateOrder(), removeOrder(), getAllOrders().
- Main – демонстрация: добавление заказов, поиск по номеру столика, обновление, удаление, вывод всех заказов.

## Демонстрация работы хэш-таблицы
- Хэш-функция преобразует номер столика в индекс массива
- Коллизии разрешаются методом цепочек (связанные списки)
- При добавлении заказа с существующим ключом значение обновляется

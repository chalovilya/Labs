# Лабораторная работа №7: Многопоточность (Вариант 2, Вариант 2, Вариант 10)

## Задание 1: ArraySumThreads.java (Вариант 2)
Сумма элементов массива с использованием пула потоков.

- Создание пула потоков с помощью ExecutorService
- Разделение массива на равные части
- Каждую часть обрабатывает отдельный поток
- После завершения всех потоков результаты суммируются в главном потоке

## Задание 2: MatrixMaxThreads.java (Вариант 2)
Поиск наибольшего элемента в матрице с использованием пула потоков.

- Создание пула потоков с помощью ExecutorService
- Разделение матрицы на равные части
- Каждый поток обрабатывает свою часть матрицы
- После завершения всех потоков результаты сравниваются в главном потоке для нахождения наибольшего элемента

## Задание 3: WarehouseTransfer.java (Вариант 10)
Перенос товаров со склада с использованием Executor и CompletionService.

- 3 грузчика работают одновременно
- Суммарный вес товаров за рейс не более 150 кг
- Executor для управления потоками грузчиков
- CompletionService для получения результатов выполнения
- Как только набрано 150 кг, грузчики отправляются на другой склад

## Запуск
```bash
java ArraySumThreads
java MatrixMaxThreads
java WarehouseTransfer
